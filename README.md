# plan-to-map-converter

Исходный код двух процессов отрисовки планов офисов для системы бронирования рабочих мест:

- `code/map/` — адаптированная карта офиса: приём исходника (растр, PDF, чертёж), сборка SVG, проверки приёмки, мост «инженерный план → карта».
- `code/plan/` — инженерный план: DXF и SVG из плоского PDF или листа CAD со слоями, проверки, служебные скрипты.
- `tools/` — вспомогательные скрипты.

## Чего здесь нет

Правил процесса, исходников и готовых планов клиентов, эталонных данных регрессии и описей выпусков. Это только код. Пути в скриптах задаются переменными окружения; значения по умолчанию — рабочие каталоги авторов и в других окружениях их нужно задать.

## Состояние

Снимок кода октября 2026 года, история начата заново. Версия и пакет зависимостей в репозитории не зафиксированы: Python 3, `numpy`, `shapely`, `Pillow` и другие библиотеки подбираются по импортам.
